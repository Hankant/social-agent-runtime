# 来源与维护边界

本skill从用户在ABM_INFO中的多agent仿真开发与故障处理中提炼，不是SocioVerse官方组件。2026-11-06核查的参考checkout为`socioverse2-contest`，commit `7052ec0`。这些定位仅供溯源，使用本skill不需要原项目或其目录。

| 可复用内容 | 核查来源（仓库相对路径） | 泛化处理 |
|---|---|---|
| 冻结观察、滚动补位、稳定返回、错误收尾 | app_v6/model.py 的 decide_batch | 新写独立基础模块，不导入研究模型 |
| 预算、请求身份、成功缓存、有限输出重试 | app_v6/llm_client.py | 写成adapter合同，保留供应商语义差异 |
| 全局限流、降低并发与逐步恢复 | app_v6/throttle.py | 提炼策略，并修正每线程失败各自减半的通用风险；历史参数不是固定默认 |
| 未决结果及显式恢复 | app_v6/recovery.py | 区分未决结果、未知usage和已完成状态 |
| 离线并发/恢复测试 | app_v6/test_concurrency.py、test_recovery.py、test_rate_limit.py | 独立可控fake测试；不继承历史通过数 |
| 评论与记忆导致输入膨胀 | compact_prompt.py、concise_wire.py、相关docs | 统计真实发送内容；不把全部阅读或特定窗口当普遍要求 |

582人、305/277角色配比、政府介入、PB/RC/GT/RF、TBU、同根转发限制、MBTI、三轮记忆、50条评论、MiniMax-M3、10线程、套餐上限都属于特定项目选择，不是skill默认模型。失败下线尤其需要目标研究事先定义，并保留其可能造成选择性缺失的解释边界。

本包以新写的指令、基础代码和离线测试为主；没有捆绑第三方框架、账户数据、真实回答或凭据。后续升级优先更新adapter、故障矩阵和供应商文档核查，不把短期SDK参数写成永恒规则。新增场景应能通过自身合同接入，而不修改旧实验。

用户提供的研究边界与当前项目规则优先于示例参数。历史运行正常完成不等于当前代码、行为模型或现实解释已经验证。
